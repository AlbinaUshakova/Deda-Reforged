# Deda Product Direction

Date: 2026-09-03

## Core promise

Deda is the fastest way to start reading in a language with an unfamiliar script.

The product helps learners stop being intimidated by unfamiliar symbols and start reading real words early.

## Anti-scope

Deda is not a full language course. It should not position itself primarily around:

- speaking fluency;
- grammar coverage;
- broad vocabulary growth;
- handwriting;
- general travel phrase training.

## Product principles

- Reading comes before full alphabet memorization.
- Lessons use only symbols already introduced.
- The first real reading success should happen in the first session.
- Transliteration is temporary support, not the main layer.
- Lessons stay short and mobile-friendly.

## Target catalog

- Korean

- Japanese
